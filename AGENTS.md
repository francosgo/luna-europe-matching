# Agent entrypoint

Read README.md, docs/ARCHITECTURE.md and docs/MODEL_CARD.md before changes.
The invention record is docs/INVENTION_RECORD.md; operational history is docs/BUILD_LOG.md.
Use synthetic examples and fixtures only. Never commit private profiles, job applications,
photos, credentials, database files, hidden local state or raw feedback.
Preserve source IDs, explicit uncertainty, optimistic concurrency and version-specific approval.
Do not convert case studies into employment, learning into professional expertise, or fit scores into hiring probabilities.
Run `python -m unittest discover -s tests -v` and check changed JavaScript with `node --check`.
Natural-language change requests are pending work, not completed revisions.
Payments are optional test adapters; do not enable live billing automatically.
This local service binds only to loopback. Public multi-user hosting requires a separate authenticated service.
